## 실행 스크립트

```bash
# 전체 크롤링 (bugFixes 없는 패치 대상)
npx tsx scripts/crawl-bug-fixes.ts

# 특정 패치만
npx tsx scripts/crawl-bug-fixes.ts --patches=3444,3423

# 드라이런
npx tsx scripts/crawl-bug-fixes.ts --dry-run

# 이미 처리된 패치 재처리
npx tsx scripts/crawl-bug-fixes.ts --force
```
