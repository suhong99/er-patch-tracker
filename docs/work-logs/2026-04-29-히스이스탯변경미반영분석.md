## 근본 원인 요약

```
1. loadExistingCharacters() → characterMap 로드 (baseStats 포함 안 됨, CharacterData 타입)
2. applyBaseStatChangesFromPatch() → Firestore docRef.update({ baseStats: new값 })
3. saveCharacters(characterMap) → batch.set(docRef, characterMap[name]) → baseStats 덮어씀!
```

수정 후 순서:

```
1. loadExistingCharacters()
2. saveCharacters(characterMap)          ← 먼저 실행
3. applyBaseStatChangesFromPatch()       ← 그 다음 실행 (덮어쓰기 없음)
```
