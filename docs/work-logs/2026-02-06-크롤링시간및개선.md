#### 2. 크롤링 파싱 로직 개선 (대칭 파싱)

**문제점**: stat/before/after 파싱이 비대칭적이었음

- 예: stat="초과된 공격 속도", before="0.01 당 스킬 증폭 1.2", after="1.0"
- 올바른: stat="초과된 공격 속도 0.01 당 스킬 증폭", before="1.2", after="1.0"

**해결 방법**: `findSymmetricStartInBefore()` 함수 구현

- after 값의 패턴을 분석하여 before에서 대칭적인 시작점 찾기
- 패턴 1: 슬래시 구분 (`30/60/90...`) → before의 첫 번째 `숫자/` 패턴 위치
- 패턴 2: 괄호 시작 (`(공격력의 102%)`) → before의 첫 `(` 위치
- 패턴 3: 일반 숫자 (`3%`, `3.3%`) → before의 마지막 `공백+숫자` 위치
- 추가: 괄호 내부의 숫자는 무시 (depth 추적)
