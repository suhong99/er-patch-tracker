# 파서 H2 섹션 버그 수정 + 회귀 테스트 픽스처 추가

## 날짜: 2026-03-13

## 문제

패치 3406에서 `아이템 스킬` 섹션이 **H2 태그**로 작성되어 있어,
파서가 이를 섹션 종료로 인식하지 못하고 직전 캐릭터(현우)의 변경사항으로 잘못 파싱.

### 원인

`parsePageContent` 내 `allElements` 필터:

```ts
const allElements = Array.from(content.children).filter(
  (el) => el.tagName === 'P' || el.tagName === 'UL' || el.tagName === 'H5'
);
```

H2 태그를 필터에 포함하지 않아 → H2를 아예 건너뜀 → 실험체 섹션이 닫히지 않음.

## 해결책

1. `allElements` 필터에 `H2`, `H3` 추가
2. 실험체 섹션 내에서 H2/H3를 만나면 → 현재 캐릭터 저장 후 루프 종료

## 진행 상태: 완료

## 변경 파일

- `scripts/parse-balance-changes.ts` - H2/H3 섹션 경계 처리 추가
- `scripts/tests/fixtures/3406/` - 회귀 테스트 픽스처 (수동 추가 필요)

## 픽스처 생성 방법 (사용자 작업 필요)

파서 수정 후, Firebase 접근 가능한 환경에서:

```bash
npx tsx scripts/tests/generate-fixtures.ts --patches=3406
```

생성된 `expected.json`을 확인하고 현우에게 아이템 스킬 내용이 없는지 검증.
