## 진행 상황

### 2026-02-24

**배경**: 게임사가 패치노트(ID: 3376, "서버 점검 완료 및 패치노트 추가 내용 안내")를 patchnote 카테고리가 아닌 일반 news로 분류하여 자동 크롤링에서 누락됨.

**작업 내용**:

1. **`add-single-patch.ts` 구현**
   - 뉴스 목록 API(카테고리 필터 없음)에서 게시글 정보 가져오기
   - `patchNotes` 컬렉션에 `hasCharacterData=true, status=success`로 저장
   - `parse-balance-changes.ts` 자동 실행 (Firebase 등록 실험체만 필터링)
   - `--dry-run` 옵션: 저장 없이 파싱 미리보기

2. **`parse-balance-changes.ts` 버그 수정**
   - **문제**: after 값이 `<strong><span>` 별도 태그에 있는 경우 파싱 누락
   - **원인**: `descSpan.textContent`로 첫 번째 span만 읽어 `→` 뒤 값이 없는 케이스
   - **수정**: `→`가 있지만 패턴 매칭 실패 시 `descP.textContent`로 fallback
   - **영향**: 헨리 (시간 제어 장치(W) 이동 속도 감소 25% → 30%) 파싱 누락 수정

3. **헨리 3376 데이터 수동 추가**
   - `patchId: 3376`, `overallChange: buff`, `devComment: null`
   - 변경사항: 시간 제어 장치(W) 이동 속도 감소 25% → 30%
   - `patchNotes/3376` characterNames에 헨리 추가

## 실행 스크립트

### 누락 패치 추가 (전체 파이프라인)

```bash
npx tsx scripts/add-single-patch.ts --id=<게시글ID>
```

### 미리보기만 (저장 없음)

```bash
npx tsx scripts/add-single-patch.ts --id=<게시글ID> --dry-run
```
