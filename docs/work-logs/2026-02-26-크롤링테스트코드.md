## 배경

스크립트 개선 과정에서 기존 패치들이 잘못 파싱되는 회귀 버그가 발생함.
특정 패치 ID의 크롤링 결과를 픽스처로 저장해두고, 스크립트 수정 후에도 동일한 결과가 나오는지 검증.

## 전략

1. **픽스처 생성**: 현재 스크립트로 특정 패치 크롤링 → HTML + 파싱 결과 저장
2. **테스트**: 저장된 HTML을 Puppeteer에 로드 → 파싱 → 픽스처와 비교

```
scripts/
  tests/
    fixtures/
      {patchId}/
        content.html   ← .er-article-detail__content outerHTML
        expected.json  ← 파싱 결과 (ParsedCharacter[])
        characters.json ← 유효 캐릭터 목록
    generate-fixtures.ts  ← 픽스처 생성 스크립트
    parse.test.ts         ← 테스트 파일
```

## 실행 스크립트

### 1단계: 픽스처 생성 (처음 1회 + 기준 변경 시)

```bash
npx tsx scripts/tests/generate-fixtures.ts --patches=1234,5678,9012
```

### 2단계: 테스트 실행

```bash
npm run test
```
