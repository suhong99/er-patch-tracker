## 배경

실험체가 버프/너프를 받으면 기본 스텟(HP, 방어력, 공격력 등)이 변경된다.
현재 `upload-character-stats.ts`는 변경 여부와 무관하게 항상 덮어쓰고,
어떤 캐릭터의 스텟이 달라졌는지 감지하지 못한다.

## 실행 스크립트

### 1단계: 스텟 크롤링

```bash
npx tsx scripts/crawl-character-stats.ts
# 특정 캐릭터만: npx tsx scripts/crawl-character-stats.ts 윌리엄
```

### 2단계: 변경된 스텟만 업데이트

```bash
npx tsx scripts/upload-character-stats.ts
# 전체 강제 업데이트: npx tsx scripts/upload-character-stats.ts --force
# 미리보기: npx tsx scripts/upload-character-stats.ts --dry-run
```
