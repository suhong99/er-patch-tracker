## Firestore 데이터 모델

```
patchNotes/{patchId}
  bugFixes: [{ character: string|null, description: string }]

characters/{name}
  bugPatchIds: number[]     ← 버그 있었던 패치 ID 목록 (중복 제거, 내림차순)
  totalBugCount: number     ← 총 버그 언급 횟수
```

### 버그 픽스처 생성 (기존 HTML 재사용, 빠름)

```bash
npx tsx scripts/tests/generate-bug-fixtures.ts --patches=3444,3423,3327,1843,1812,1802,1286
```

```bash

```

### Firebase 업로드

# fixtures/ 내 bugs.json 있는 패치 전부
npx tsx scripts/upload-bug-fixes.ts

## 관련 파일

- `scripts/parse-bug-fixes.ts` ← 버그 파서 (신규)
- `scripts/tests/generate-bug-fixtures.ts` ← 버그 픽스처 생성기 (신규)
- `scripts/tests/generate-fixtures.ts` ← 밸런스 픽스처 생성기 (기존, 수정 없음)
- `scripts/tests/parse.test.ts` ← 버그 파싱 테스트 추가됨
- `scripts/tests/fixtures/<patchId>/bugs.json` ← 버그 픽스처
